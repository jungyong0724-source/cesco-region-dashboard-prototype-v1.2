# 내 지역 현황판 — Phase 1.2 프로토타입 (조회 전용 축소판)

세스코 "내 지역 현황판" Phase 1(법정동 기반 KODATA 조회)의 **조회 전용(read-only)** 개선판입니다.
Phase 1.5 프로토타입에서 "저장이 필요한" 기능(방문상태 기록·통계 대시보드·레드존)을 걷어내고,
Phase 1 실서비스에서 불편했던 UX·필터만 손봤습니다.

- 순수 HTML/CSS/JS, 목업(mock) 데이터 기반 데모입니다. 실제 백엔드 API와 연결되어 있지 않습니다.
- 지도는 Leaflet + OpenStreetMap 타일을 사용합니다.

## Phase 1.5 대비 변경점

| 구분 | 내용 |
|---|---|
| 제거 | 현장 방문 관리(담당사원·방문날짜·메모·고객코드·상태전이), 실시간 통계 대시보드, 레드존 뱃지 |
| 지사 필터 | 2단계(사업부→지사) → **3단계(조직축 세스코/CLC → 사업부·총국 → 지사·지국)**. CLC 총국/지국 목록은 데이터팀 확인 전 임시 mock |
| 업종 태그 | 카드/상세 두 번째 태그를 표준산업분류(KSIC)명 → **마케팅 신업종명**으로 교체. 필터화면의 "산업분류(10차)" 섹션 제거 |
| 개업기간 | 4구간 단일 필터 유지 + **개업 1년(365일) 초과 매장은 "전체"에서도 상시 제외** |
| 내 주위 | "내 주위 미계약 보기" → **"내 주위 신규 개업 매장 보기"**(계약 여부 판별 없음), 내 위치 지도 마커 상시 표시 |

## 실행 방법

별도 빌드 없이 정적 파일이므로 로컬 웹 서버로 `index.html`을 열면 바로 동작합니다.
(`file://`로 직접 열면 일부 브라우저 보안 정책상 정상 동작하지 않을 수 있습니다.)

```
npx serve .
```

또는 GitHub Pages로 배포된 데모 링크를 사용하세요.
